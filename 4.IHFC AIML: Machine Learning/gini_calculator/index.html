3. Step-by-Step Mathematics

Parent Node Impurity
Gini = 1 - (p_A^2 + p_B^2)
1 - ((4/7)^2 + (3/7)^2) = 0.4898
Left Child Node Impurity
Gini = 1 - (p_A^2 + p_B^2)
1 - ((3/3)^2 + (0/3)^2) = 0.0000
Right Child Node Impurity
Gini = 1 - (p_A^2 + p_B^2)
1 - ((1/4)^2 + (3/4)^2) = 0.3750
Weighted Children Impurity
Weighted = (N_Left/N) * Imp_Left + (N_Right/N) * Imp_Right
(3/7) * 0.0000 + (4/7) * 0.3750 = 0.2143
Gain (Reduction in Impurity)
Gain = Imp_Parent - Weighted_Children
0.4898 - 0.2143 = 0.2755
